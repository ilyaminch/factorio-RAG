# Embeddings and vector search

`index.py` stores embedded Wiki chunks in local Qdrant. `query.py` retrieves five passages with ranks, scores and source URLs for RAG context.

| Setting | Value |
| --- | --- |
| FastEmbed model | `intfloat/multilingual-e5-large` |
| Vector size / metric | 1024 / Cosine |
| Collection | `factorio_wiki` |
| Storage | `QDRANT_PATH` (default: `qdrant_db/` at the project root) |
| Upload / embedding batch | 100 / 4 chunks |
| Model cache | `data/models/` (ignored by Git) |

[E5](https://huggingface.co/intfloat/multilingual-e5-large) embeds the English Wiki corpus for semantic retrieval. Embedding inputs use `passage: ` for documents and `query: ` for questions; stored text stays unchanged. Inputs are truncated at 512 tokens. First use downloads about 2.24 GB of weights; allow additional inference memory and time for CPU indexing.

## Indexing

Install the root `requirements.txt`, then run from the repository root:

```powershell
python -m src.database.index
```

Input: `data/processed/chunks.jsonl`, generated by [data_pipeline](../data_pipeline/README.md). Each chunk UUID becomes a point ID; its text and metadata become the payload.

**Rebuild after changing the model or dataset:** close database processes, move `qdrant_db/` to a backup folder, then index all chunks. Both scripts reject incompatible dimensions or metrics; matching dimensions alone do not guarantee matching models. Upsert updates matching IDs but leaves stale IDs.

## Search

```powershell
python -m src.database.query "What ingredients are needed for steel plates?" "How do robots recharge?"
```

Each quoted argument is a question; the default is `Recipe: steel plate`. The model loads once. Scores measure similarity, not answer correctness.

Search covers all sections without a hard section filter, including recipes, characteristics and game mechanics. Run indexing and search sequentially: local storage allows one process at a time.

`index.py`, `query.py` and the Streamlit retriever use `src/config.py`. Environment overrides include `QDRANT_PATH`, `CHUNKS_PATH`, `COLLECTION_NAME`, `EMBEDDING_MODEL` and `VECTOR_SIZE`; defaults are E5 large / 1024 / `factorio_wiki`. `FASTEMBED_CACHE_PATH` overrides the model cache.

## RAG integration

`create_retriever(settings)` in `retriever.py` returns an object with `search(query, limit=4)` and `close()`. Results follow `SearchHit`: `chunk_id`, `text`, `title`, `section`, `url`, `game_variant`, `score`. URLs prefer section links. Missing/empty databases or incompatible vectors raise `ProjectError`; the retriever does not create collections. Close it when finished to release the local storage lock.

Streamlit already connects this factory to `src.rag.service.answer`. Completed turns are kept in session memory; the service rewrites follow-up questions using recent history, retrieves context, and generates cited answers. `HISTORY_TURNS` controls the history window. Memory is not persisted after the session ends.

For the complete app, install `deploy/requirements.txt`, set `MISTRAL_API_KEY`, `MISTRAL_MODEL` and, for a compatible proxy, `MISTRAL_BASE_URL`, then run from the project root:

```powershell
python -m streamlit run streamlit-app/app.py
```

Keep credentials in the process environment or a private deployment env file; do not commit them.

## Retrieval check

Checked **2026-11-14** on **3271 indexed chunks** through `query.py`, using English questions and no section filter. Required: first relevant hit at rank 1–2 and at least three relevant hits in the top five. Manual judgments accept partial factual answers, not merely related topics; distinct chunks of one article may count.

| Question | First relevant rank | Relevant hits in top five | Pass |
| --- | --- | --- | --- |
| What ingredients and crafting time are needed to make steel plates? | 1 | 4 | Yes |
| Which mining drills can mine iron ore? | 1 | 4 | Yes |
| How does the circuit network transmit signals and control machines? | 1 | 5 | Yes |
| How can heavy oil be cracked into light oil? | 1 | 2 | No |
| How do logistic and construction robots store energy and recharge? | 1 | 4 | Yes |

**Result: 4/5 questions meet both requirements.** Every question has a relevant result at rank 1. For oil cracking, the first hit contains the complete recipe, but the top five also contain light-oil-to-petroleum cracking, a cookbook fragment missing context and a table fragment. These do not answer the requested conversion.

Possible causes and proposed improvements:

- **Ranking:** related oil processes compete with the requested conversion. Retrieve more candidates and rerank by the question; consider hybrid keyword/vector retrieval using recipe inputs and outputs.
- **Chunk boundaries:** retain recipe/table headers and enough parent context so continuation chunks can stand alone. In addition, 42 chunks exceed E5's 512-token limit (maximum 1072). Split by tokens to avoid losing their endings during embedding.

The hard section filter has been removed. Further ranking and preprocessing improvements are proposals; validate them on these questions and additional unseen ones.

Integration checked with real Qdrant, E5 and the configured LLM: follow-up rewriting and topic changes worked. A two-turn Streamlit check also preserved history and returned cited sources.
